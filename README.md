# Claims Triage AI

## Implementation status — 9 October 2026
This repository is documentation only (README). No runnable app, AI model, intake endpoint or deployed claims system is included. The features below are proposed, not implemented or certified. Use synthetic examples and qualified human review; do not upload confidential claims or rely on this concept for coverage or routing decisions.

## Proposed workflow
FNOL intake, claim categorization, severity scoring and routing to an adjuster queue. Intended audience: insurers, MGAs, brokers and claims teams. A future implementation must document evidence, errors, permissions and human approval.
